실시간 새 채팅 표본을 기다리고 있어요.

동일한 요청 ID와 답글 ID로 응답·DOM 반영을 짝지어 측정합니다. 전체는 요청 시작 → 응답의 새 답글이 DOM에 추가된 후 다음 프레임까지입니다. 요청 시간에는 서버 대기·외부 조회·DB·전송이 함께 포함되며 내부 구간을 따로 측정한 값은 아닙니다. X 게시 시점이나 카운트 변화 → 수집 시작 전의 시간은 측정할 수 없습니다. ±는 최근 100회 표본의 표준편차입니다. 첫 기록·이전 기록·종료된 방송·자동 스크롤 해제·백그라운드는 제외하며, 애니메이션 종료 시간은 포함하지 않습니다.
