Vercel 통계 연결

Vercel에서 발급한 토큰으로 이 프로젝트의 공식 방문 통계를 읽습니다. 토큰은 서버에서 암호화해 저장하며 화면에 다시 표시하지 않습니다.

토큰 설정 열기

범위: bicheondevs-projects. 만료되거나 조회 권한이 없으면 오류를 표시합니다.

GA4 속성에 뷰어 권한이 있는 Google 서비스 계정을 연결합니다. 키는 서버에 암호화 저장됩니다.

① Google Cloud에서 Google Analytics Data API를 사용 설정하고 서비스 계정의 JSON 키를 발급합니다.
② GA 관리 → 속성 액세스 관리에서 서비스 계정 이메일을 뷰어로 추가합니다.
③ 아래에 숫자 속성 ID와 JSON 키를 입력합니다.
